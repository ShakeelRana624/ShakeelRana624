- Achieved **93.6% weapon-detection mAP** and **2.29-second responder dispatch latency** during project testing.
- Combined YOLOv8-based detection, multi-agent orchestration, Firebase, Flask, and Flutter.

**2. Computer Vision - Drone Detection**

- Developed a YOLO11-based drone detection model achieving **92.5% mAP@50**.

- Explored object tracking, false-positive analysis, hard-negative mining, and ONNX inference.

**3. Fintech Fraud Detection**

- Built an XGBoost-based transaction fraud detection system using the PaySim synthetic dataset.
- Implemented feature engineering, imbalanced-data handling, cross-validation, and SHAP explainability.
- Integrated model predictions through a Flask API and interactive dashboard.

**4. Customer Churn Prediction**

- Developed an end-to-end machine learning application for telecom customer churn prediction.
